Enhanced jqxGrid

Cell templates

Rich cells without writing a cellsrenderer. Add a declarative cellTemplate to any column — a moustache string like {{first}} {{value | c2}}, or a built-in like { type: 'badge' }. It compiles to a standard renderer, so sort, filter, page and export keep working.

Drop in jqxgrid.celltemplates.js and set cellTemplate on a column: 
{ text: 'Status', datafield: 'status',
  cellTemplate: { type: 'badge', colors: { Active: 'green', Churned: 'red' } } }

{ text: 'Owner', datafield: 'name', cellTemplate: { type: 'avatar', subField: 'email' } }

{ text: 'Price', datafield: 'price', cellTemplate: '{{value | c2}}' }
Register your own: $.jqx.cellTemplates.myThing = function (value, row, opts) { return '...'; }
