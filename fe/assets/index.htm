Start with the demos

3,600 runnable examples for 80+ components — JavaScript, TypeScript, Angular, React and Vue — in one searchable browser with live preview, theme switching, source view and one-click StackBlitz export.

Open the Demo Browser → or, for the full experience, double-click start-demos.cmd / run sh start-demos.sh

JavaScript / jQuery

Include jqwidgets/jqxcore.js, the widget files you need and a theme. No build step.

<link rel="stylesheet" href="jqwidgets/styles/jqx.base.css">
<link rel="stylesheet" href="jqwidgets/styles/jqx.fluent.css">
<script src="scripts/jquery-3.7.1.min.js"></script>
<script src="jqwidgets/jqxcore.js"></script>
<script src="jqwidgets/jqxgrid.js"></script>

Angular

Angular 19 or newer. Standalone components import from jqwidgets-ng/<widget>.

npm i jqwidgets-ng
import { jqxGridModule } from 'jqwidgets-ng/jqxgrid';

React

React 16.8 – 19. Class-based wrappers with full typings; use a ref to call widget methods.

npm i jqwidgets-scripts
import JqxGrid from 'jqwidgets-scripts/jqwidgets-react-tsx/jqxgrid';

Vue

Vue 3 wrappers in jqwidgets-vue3/ (Composition API, SSR-safe). Vue 2 wrappers remain in jqwidgets-vue/.

npm i jqwidgets-scripts
import JqxGrid from 'jqwidgets-scripts/jqwidgets-vue3/vue_jqxgrid.vue';

What is in this folder

jqwidgets/The SDK: jqxcore.js, one file per widget, jqx-all.js (everything), modules/ (bundled per-widget builds), globalization/, and styles/ with the base stylesheet, 38 themes and their images. In general you need files from this folder only.
jqwidgets-ts/TypeScript definitions (jqwidgets.d.ts) and the Angular component sources (angular_jqx*.ts).
jqwidgets-react-tsx/React components (ESM + UMD builds with typings, one folder per widget).
jqwidgets-vue3/ & jqwidgets-vue/Vue 3 and Vue 2 single-file components.
demos/Demo Browser · Javascript & JQuery/ (also API reference pages under documentation/; the old jQuery Mobile set is still on disk under mobiledemos/ but is not offered in the browser) · Typescript/ · Angular/ · React-TSX/ · Vue.js/ · Showcase/ (full sample apps) · ASP.NET MVC/, ASP.NET Tag Helpers/, JSP/, PHP/ (server integration; the PHP samples need the Northwind MySQL database from demos/PHP/Northwind.MySQL5.sql) · Angular1.x/ (legacy AngularJS) · sampledata/ shared by all demos.
scripts/, styles/, images/Third-party libraries and assets used only by the demos (jQuery, Bootstrap, Knockout, RequireJS, …), plus scripts/serve-demos.js and scripts/build-demo-catalog.js which power the Demo Browser.

Any demo that loads data with Ajax must be served over http://. start-demos.cmd / start-demos.sh does that with a single-file Node.js server and opens the Demo Browser.
